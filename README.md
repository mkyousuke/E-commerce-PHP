# GameShop

Site e-commerce de vente de jeux vidéo développé en PHP et MySQL.

---

## Installation

Suivez ces étapes pour configurer le projet localement :

1. **Copie du projet** : Placez le dossier du projet dans votre répertoire serveur local (ex: `C:\xampp\htdocs\GameShop`).
2. **Base de données** : Ouvrez phpMyAdmin et créez une nouvelle base de données nommée `gameshop_db`.
3. **Importation** : Importez le fichier `gameshop_db.sql` se trouvant dans le dossier `BDD`.
4. **Configuration** : Vérifiez et ajustez les paramètres de connexion dans le fichier `config/db.php`.
